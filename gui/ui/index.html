    Extend an ensemble

    Carry an earlier run’s chain on for longer. Its settings come from its own directory, not from the Build tab — extending continues one chain, and changing its parameters halfway would make it a different one. The earlier run must have kept its plans.

    If that run was segmented the result is byte-identical to one run of the full length. If it was not, the chain is still continued — valid, since ReCom is Markov — but it will not match.

    What has been downloaded

    One directory per state and version, so pinning an older version never evicts a newer one. It adds up: every state is about 780 MB.
